# 面向骨髓增殖性疾病的 JAK2 信号轴抑制剂效能深度学习识别

> 围绕 JAK-STAT 信号在骨髓增殖性肿瘤中的驱动作用，用深度学习识别 JAK2 抑制剂效能档位，辅助精准用药。

## 一、方法

- **模型**：一维空洞卷积神经网络（SMILES 字符级）

- **输入**：SMILES 字符级 token 序列
- **训练规模**：2500 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
